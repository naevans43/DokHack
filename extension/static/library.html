스캔 설정

기본적으로 독해크는 페이지를 열어도 아무것도 표시하지 않아요. 툴바의 독해크 아이콘에서 ‘이 페이지 스캔하기’를 누르면 그 페이지의 모르는 단어가 표시돼요.

단어 위에 마우스를 올린 채 숫자 키를 누르면 클릭하지 않고도 상태가 바뀌어요: 1 모름, 2 봤어요, 3 학습 중, 4 알아요. 유튜브에서는 단어 위에 마우스가 있을 때만 이렇게 동작하고, 다른 곳에서는 숫자 키가 원래대로 영상을 이동해요.

켜면 모든 영어 페이지에서 바로 단어가 표시돼요. 페이지가 많이 칠해져 보이거나 브라우저가 느려진다면 꺼 두세요.

모르는 단어의 카드를 열면 파란색에서 주황색으로 바뀌어, 확인만 해 본 단어와 한 번도 안 본 단어를 구분해 줘요. 이미 정한 상태는 바꾸지 않아요.

기본은 꺼져 있어요. 대본 패널 위쪽의 ‘줄마다 멈춤’ 버튼으로도 켜고 끌 수 있어요.

아주 자주 쓰이는 단어(상위 3,000개)에는 빨간 밑줄이 생겨요. 먼저 익히면 좋은 단어예요. 드문 단어에는 회색 점선 밑줄이 생겨요. 빈도 자료: OpenSubtitles 2018 자막 빈도 목록(hermitdave/FrequencyWords, CC BY-SA 4.0).

다시 보기 좋은 영상

자막 단어의 95% 이상을 알면서 1분 넘게 본 유튜브 영상이에요. 딱 좋은 난이도라 한 번 더 보면 좋아요. 이 목록은 이 기기에만 저장되고 동기화되지 않아요.

    아직 없어요. 유튜브에서 스캔한 채로 영상을 보면 여기에 모여요.

    카드 내보내기

    이 기기에 저장된 카드를 파일로 내려받아요. 유튜브에서 캡처한 소리와 화면도 Anki용 zip에 함께 들어가요.

    단어 목록 가져오기

    이미 아는 단어를 한 번에 표시할 수 있어요. 단어 목록(한 줄에 하나), Anki에서 ‘노트를 일반 텍스트로’ 내보낸 파일, 아무 영어 글이나 괜찮아요. 단어는 기본형으로 바꿔서 저장하고, 이미 표시한 단어는 건드리지 않아요.

    아는 단어 자동 표시

    몇 가지 단어를 보고 아는 단어를 골라주면, 비슷한 수준의 자주 쓰는 단어를 한 번에 ‘아는 단어’로 표시해요. 이제 이 테스트는 복습 웹사이트에서 해요. 건너뛰고 글을 읽으면서 단어를 하나씩 직접 표시해도 괜찮아요.

    이메일로 로그인하면 저장한 카드가 복습 웹사이트에도 동기화되어, 다른 기기에서도 복습할 수 있어요.

    연결됨:

    동기화하면 저장한 카드를 올리고, 복습 웹사이트에서 충분히 잘 기억한 단어는 자동으로 알아요로 바뀌어요.
