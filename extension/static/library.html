    스캔 설정

    기본적으로 독해크는 페이지를 열어도 아무것도 표시하지 않아요. 툴바의 독해크 아이콘에서 ‘이 페이지 스캔하기’를 누르면 그 페이지의 모르는 단어가 표시돼요.

    켜면 모든 영어 페이지에서 바로 단어가 표시돼요. 페이지가 많이 칠해져 보이거나 브라우저가 느려진다면 꺼 두세요.

    모르는 단어의 카드를 열면 파란색에서 주황색으로 바뀌어, 확인만 해 본 단어와 한 번도 안 본 단어를 구분해 줘요. 이미 정한 상태는 바꾸지 않아요.

    기본은 꺼져 있어요. 대본 패널 위쪽의 ‘줄마다 멈춤’ 버튼으로도 켜고 끌 수 있어요.

    단어 목록 가져오기

    이미 아는 단어를 한 번에 표시할 수 있어요. 단어 목록(한 줄에 하나), Anki에서 ‘노트를 일반 텍스트로’ 내보낸 파일, 아무 영어 글이나 괜찮아요. 단어는 기본형으로 바꿔서 저장하고, 이미 표시한 단어는 건드리지 않아요.

    아는 단어 자동 표시

    몇 가지 단어를 보고 아는 단어를 골라주면, 비슷한 수준의 자주 쓰는 단어를 한 번에 ‘아는 단어’로 표시해요. 이제 이 테스트는 복습 웹사이트에서 해요. 건너뛰고 글을 읽으면서 단어를 하나씩 직접 표시해도 괜찮아요.
