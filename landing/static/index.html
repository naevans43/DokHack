독해크

읽으면서 배우는 영어 단어장

영어 글을 읽다가 모르는 단어를 클릭하면 뜻이 뜨고, 그 문장을 그대로 카드로 저장할 수 있어요. 예: peptide는 기억 중이라는 뜻이에요.

시작하는 방법 보기 복습 사이트로 이동

어떻게 동작하나요

사전을 따로 찾지 않아도, 글을 읽는 흐름을 끊지 않고 단어를 익힐 수 있어요.

  1. 모르는 단어를 클릭하세요.

    영어 정의와 한국어 뜻을 바로 보여줘요. 둘 다 실제 사전(WordNet, KRDICT)에서 가져온 것으로, AI가 지어낸 뜻이 아니에요.

  2. 상태를 표시하세요.

    모름 / 학습 중 / 알아요 세 가지로 표시하면, 페이지의 단어들이 그에 따라 색이 바뀌어요. "알아요"로 표시한 단어는 다음부터 색이 없어져서, 진짜 모르는 단어만 눈에 띄어요.

  3. 문장을 카드로 저장하세요.

    클릭한 단어가 있는 문장을 그대로, 또는 앞뒤 문장을 더 붙여서 카드로 저장해요. 한국어 뜻과 영어 뜻 중 원하는 것만 골라 담을 수 있어요.

  4. 다른 기기에서 복습하세요.

    저장한 카드는 간격 반복(FSRS) 알고리즘으로 복습 사이트에서 복습해요. 확장 프로그램이 없는 휴대폰에서도 가능해요.

무엇이 다른가요

단어장 앱을 새로 여는 대신, 지금 읽고 있는 글 자체가 단어장이 돼요.

페이지를 고치지 않아요

단어에 색을 입히는 방식이 페이지 구조를 바꾸지 않아서, 사이트가 느려지거나 깨지지 않아요.

AI가 아니라 사전이에요

모든 뜻은 WordNet과 KRDICT(국립국어원) 데이터에서 직접 찾아요. 인터넷 연결 없이도, 네트워크 호출 없이도 작동해요.

숙어도 하나로 인식해요

"give up", "as a result"처럼 여러 단어가 모여 하나의 뜻이 되는 표현도 통째로 인식해서 따로따로 헷갈리지 않아요.

유튜브 자막도 돼요

영상의 스크립트(transcript)를 열면, 자막 문장에서도 똑같이 단어를 클릭하고 카드로 저장할 수 있어요.

시작하는 방법

둘 중 편한 쪽으로 시작하면 돼요. 나중에 마음이 바뀌어도 전혀 문제없어요.

추천

아는 단어 자동 표시

짧은 테스트에서 아는 단어를 몇 개 골라주면, 비슷한 수준의 자주 쓰는 단어를 한 번에 "알아요"로 표시해줘요. 처음부터 페이지가 온통 파랗게 보이지 않도록 해주는 지름길이에요.

확장 프로그램 아이콘 → 저장한 문장 보기 → 아는 단어 자동 표시

그냥 읽으면서 표시하기

테스트 없이 바로 시작해도 괜찮아요. 글을 읽다가 만나는 단어를 그때그때 모름 / 학습 중 / 알아요로 표시하면 돼요. 확장 프로그램의 기본 동작이라 언제든 이 방식으로 돌아올 수 있어요.

아무 영어 페이지에서나 바로 단어를 클릭하세요.

설치하기

아직 정식으로 배포된 상태는 아니라서, 직접 빌드해서 넣어야 해요.

  1. 소스 코드를 받은 뒤, extension 폴더에서 npm install, 이어서 npm run build를 실행하세요.
  2. Chrome 또는 Whale에서 chrome://extensions (Whale은 whale://extensions)를 열고 개발자 모드를 켜세요.
  3. "압축해제된 확장 프로그램을 로드합니다"를 눌러 방금 만들어진 dist 폴더를 선택하세요.
