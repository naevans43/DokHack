독해크

읽으면서 배우는 영어 단어장

영어 글을 읽다가 모르는 단어를 클릭하면 뜻이 뜨고, 그 문장을 그대로 카드로 저장할 수 있어요. 예: peptide는 기억 중이라는 뜻이에요.

확장 프로그램 설치하기 복습 사이트 로그인

어떻게 동작하나요

사전을 따로 찾지 않아도, 글을 읽는 흐름을 끊지 않고 단어를 익힐 수 있어요.

  1. 페이지를 스캔하세요.

    툴바의 독해크 아이콘을 눌러 "이 페이지 스캔하기"를 누르면 그 페이지의 모르는 단어가 표시돼요. 독해크는 기본적으로 꺼져 있어서, 공부하고 싶지 않을 때는 페이지가 칠해지거나 느려지지 않아요.

  2. 모르는 단어를 클릭하세요.

    영어 정의와 한국어 뜻을 바로 보여줘요. 둘 다 실제 사전(WordNet, KRDICT)에서 가져온 것으로, AI가 지어낸 뜻이 아니에요.

  3. 상태를 표시하세요.

    모름 / 학습 중 / 알아요 세 가지로 표시하면, 페이지의 단어들이 그에 따라 색이 바뀌어요. "알아요"로 표시한 단어는 다음부터 색이 없어져서, 진짜 모르는 단어만 눈에 띄어요.

  4. 문장을 카드로 저장하세요.

    클릭한 단어가 있는 문장을 그대로, 또는 앞뒤 문장을 더 붙여서 카드로 저장해요. 한국어 뜻과 영어 뜻 중 원하는 것만 골라 담을 수 있어요.

  5. 이 사이트에서 복습하세요.

    저장한 카드는 간격 반복(FSRS) 알고리즘으로 복습해요. 확장 프로그램이 없는 휴대폰에서도 가능해요.

설치하기

아직 스토어에 정식 등록된 상태가 아니라서, 파일을 받아 직접 넣어야 해요. 3분이면 돼요. Chrome과 Whale에서 쓸 수 있어요.

dokhack-extension.zip 받기 (약 7 MB)

  1. 받은 zip 파일의 압축을 풀어요. 설치한 뒤에도 이 폴더를 지우면 안 되니, 오래 둘 곳에 풀어 주세요.
  2. 브라우저 주소창에 chrome://extensions (Whale은 whale://extensions)를 입력해 열고, 개발자 모드를 켜세요.
  3. "압축해제된 확장 프로그램을 로드합니다"(Whale은 "압축 해제된 확장 프로그램 로드")를 눌러, 방금 푼 폴더를 선택하세요. 폴더 안에 바로 manifest.json이 보이는 곳이어야 해요.
  4. 목록에 DokHack이 나타나면 끝이에요. 툴바의 퍼즐 아이콘에서 핀으로 고정해 두면 편해요.

이미 열려 있던 탭은 새로고침(F5)해야 스캔 버튼이 동작해요.

업데이트할 때

새 zip을 받아 기존 폴더의 파일을 덮어쓴 뒤, chrome://extensions에서 DokHack 카드의 새로고침(↻) 버튼을 누르세요. 저장한 카드는 그대로 남아요.

시작하는 방법

둘 중 편한 쪽으로 시작하면 돼요. 나중에 마음이 바뀌어도 전혀 문제없어요.

추천

아는 단어 자동 표시

짧은 테스트에서 아는 단어를 몇 개 골라주면, 비슷한 수준의 자주 쓰는 단어를 한 번에 "알아요"로 표시해줘요. 처음부터 페이지가 온통 파랗게 보이지 않도록 해주는 지름길이에요.

테스트 해보기

결과는 같은 브라우저의 확장 프로그램에 바로 반영돼요.

그냥 읽으면서 표시하기

테스트 없이 바로 시작해도 괜찮아요. 글을 읽다가 만나는 단어를 그때그때 모름 / 학습 중 / 알아요로 표시하면 돼요. 언제든 이 방식으로 돌아올 수 있어요.

아무 영어 페이지에서나 바로 단어를 클릭하세요.

알아 두면 좋은 조작

  • 단어는 스캔한 뒤에만 표시돼요. 툴바의 독해크 아이콘 → "이 페이지 스캔하기". 같은 자리의 "스캔 끄기"로 끌 수 있어요.
  • 매번 누르기 번거롭다면 같은 팝업의 "페이지를 열 때마다 자동으로 스캔"을 켜세요. (저장한 문장 보기 → 스캔 설정에서도 바꿀 수 있어요.)
  • 단어에 마우스를 올리면 클릭할 수 있다는 표시가 나타나요.
  • 단어를 연 상태에서 S 키를 누르면 카드 만들기 창이 열려요.
  • 링크나 버튼 안의 단어는 Alt + 클릭으로 열어요.
  • 단어 카드를 열면 자동으로 ‘봤어요’(주황색)로 표시돼요. 단축키는 1 모름 · 2 봤어요 · 3 학습 중 · 4 알아요예요.
  • 스캔하면 팝업에 “이 페이지 단어의 N%를 알아요”가 나와요.
  • 저장한 문장 보기에서 카드를 미리보기·편집·삭제하고, 오디오와 영상 화면까지 담아 Anki로 내보낼 수 있어요. 이미 아는 단어 목록도 가져올 수 있어요.
  • 유튜브에서는 대본 패널의 “줄마다 멈춤”을 켜면 자막 한 줄이 끝날 때마다 영상이 멈춰요. 기본은 꺼져 있어요.
  • 확장 프로그램이 없는 휴대폰에서는 이 사이트의 읽기 탭에 영어 글을 붙여넣어 같은 방식으로 단어를 확인하고 카드를 만들 수 있어요.

복습하려면 계정을 연결하세요

저장한 카드를 이 사이트로 보내려면 이메일로 로그인해요. 비밀번호 없이, 이메일로 받은 코드만 입력하면 돼요.

  1. 확장 프로그램에서 연결하기

    확장 프로그램 아이콘 → 저장한 문장 보기 → 아래쪽 "복습 웹사이트"에서 이메일을 입력하고 "코드 받기"를 누르세요. 메일이 안 보이면 스팸함도 확인해 보세요.

  2. 모두 동기화

    코드를 확인한 뒤 "모두 동기화"를 누르면 저장한 카드가 이 사이트로 올라와요. 이후 새로 저장하는 카드는 자동으로 올라가요.

  3. 이 사이트에서 로그인

    같은 이메일로 로그인하면 홈에서 오늘 복습할 카드 수를 보고 바로 시작할 수 있어요. 카드 탭에서는 카드를 검색하고 미리보기·편집할 수 있어요.

복습에서 충분히 잘 기억한 단어는 동기화할 때 자동으로 "알아요"로 바뀌어요.

유튜브에서 쓰기 실험 중

영어 자막이 있는 영상이면, 독해크가 자막 패널과 자막 바를 만들어 줘요. 자막 속 단어를 클릭해 똑같이 카드로 저장할 수 있고, 그 장면의 오디오 클립과 화면 캡처도 카드에 담을 수 있어요. 오디오는 영상을 실제로 재생하면서 녹음하기 때문에, 클립 길이만큼 시간이 걸려요. 아직 다듬는 중이라 오류가 있을 수 있어요.

무엇이 다른가요

단어장 앱을 새로 여는 대신, 지금 읽고 있는 글 자체가 단어장이 돼요.

페이지를 고치지 않아요

단어에 색을 입히는 방식이 페이지 구조를 바꾸지 않아서, 사이트가 느려지거나 깨지지 않아요.

AI가 아니라 사전이에요

모든 뜻은 WordNet과 KRDICT(국립국어원) 데이터에서 직접 찾아요. 뜻을 찾는 데 인터넷 호출이 필요 없어요.

숙어도 하나로 인식해요

"give up", "as a result"처럼 여러 단어가 모여 하나의 뜻이 되는 표현도 통째로 인식해요. "turn the lights off"처럼 떨어져 있는 경우도 찾아요.

휴대폰에서도 복습해요

확장 프로그램은 컴퓨터에서 쓰지만, 이 사이트는 휴대폰 브라우저에서도 열려서 이동 중에 복습할 수 있어요.

문제가 생기면

만든 사람에게 아래 내용을 알려 주세요: 어떤 페이지에서 무엇을 했는지, 예상과 달랐던 점(스크린샷이 있으면 좋아요), 브라우저 종류(Chrome / Whale). 특히 단어 뜻이 문맥에 맞는지, 카드 저장·동기화가 잘 되는지, 복습 화면이 휴대폰에서 편한지 봐 주시면 큰 도움이 돼요.

단어 뜻은 Princeton WordNet과 국립국어원 한국어기초사전(KRDICT, CC BY-SA) 데이터를 사용해요. 개인적으로 만들어 쓰고 있는 도구예요.
